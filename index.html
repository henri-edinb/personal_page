Predictive Coding

Inhibitory circuits play a crucial role in maintaining the stability of neural networks. Hebbian/anti-Hebbian networks have shown inhibition could also be important for learning representations. The predictive coding objective is optimized by these networks when the following constraint is satisfied:

WWT = E[yyT]

Standard Hebbian updates do not keep this constraint optimally satisfied at each inference step. Therefore, correct inference and equivalence to predictive coding requires a plasticity rule that optimizes for this constraint. The predictive rule ΔW = (y - Wx)xT ensures the update vanishes when consistency holds and corrects deviations instantly.

Asynchronous Plasticity

Models that optimize their weights via expectation-maximization have a caveat: they require the system to be in a steady state for the optimization to be effective. Here, we propose some biologically plausible mechanisms that allow latent models to learn without requiring steady-state convergence.

A post-synaptic neuron only updates its weights if it hasn't updated them in a while (refractory period) and has high firing-rate (activity-dependent threshold). We find using this kind of asynchronous learning prevents catastrophic forgetting for non-stationary distributions.
